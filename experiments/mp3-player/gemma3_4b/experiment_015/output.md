# Music Player Project

This project is a music player application with playlist management, track searching, and backup functionality.

## Overview

The application provides a user-friendly interface for managing and playing music tracks. Key features include:

*   Playlist creation and management
*   Track searching
*   Automatic backups
*   Sorting tracks by various criteria

## Technologies

*   Java
*   Swing (GUI framework)
*   ArrayList, HashTable, BinaryTree, QuickSort
*   JSlider, JTable, JTextField, JComboBox, JButton, JLabel, JPanel

## Project Structure

The project is organized into the following files:

*   `AudioPlayer.java`:  Manages the playback functionality, including audio streaming, seeking, and controls.
*   `BackupManager.java`: Handles backup operations for playlists.
*   `BinaryTrackTree.java`:  A binary tree used for efficiently storing and retrieving track information.
*   `MusicPlaylistManager.java`:  Manages the playlist interface, including playlist creation, editing, and display.
*   `MyHashTable.java`:  A hash table data structure.
*   `MyPlaylist.java`: Represents a playlist, containing a list of tracks.
*   `MySet.java`: A basic Set implementation.
*   `QuickSort.java`:  A quicksort algorithm for sorting track arrays.
*   `Track.java`: Represents a single music track with its metadata.
*   `DataStructureSmokeTest.java`:  Unit tests for the underlying data structures.


## Key Classes

*   **Track:** Represents a single music track with attributes like title, artist, album, duration, and album art.
*   **MyPlaylist:** Represents a playlist containing a list of `Track` objects.
*   **AudioPlayer:**  Handles the actual audio playback.
*   **MusicPlaylistManager:**  Manages the GUI for the playlist functionality.
*   **BackupManager:** Responsible for managing backups of playlists.
